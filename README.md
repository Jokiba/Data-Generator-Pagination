# Python projekat generator paginacija
Generator podataka i paginacija kroz upisane podatke u MySQL bazu.

## Generator podataka
Python generator vlasnika i njegovih vozila u dve posebne tabele, koje su vezane sa kolonom vlasnik_id.
Rešio sam problem datuma rođenja, sada mogu da se upišu osobe rođene pre 1970-01-01.

## Paginacija podataka
Prolaz kroz podatke pomoću tabelarnog prikaza i njegovih opcija.
Tabela vlasnik je organizovana po datumu isteka registracije vozila od najmanjeg do najvećeg datuma.
Dodata opcija Details za prikaz informacija o vozilu.

## Potrebno za pokretanje skripte
XAMPP Control Panel v3.3.0 (Apache, MySQL)
