# Python Pagination Generator - project
Data generator and pagination through data entered into the MySQL database.

## Data generator
Python generator of owners and their vehicles in two separate tables, which are linked with the owner_id column.  
I solved the problem of date of birth, now people born before 1970-01-01 can register.

## Data pagination
Step through the data using the tabular view and its options.  
The owner table is organized by vehicle registration expiration date from smallest to largest date.  
Added Details option to display vehicle information.

## Required to run the script
XAMPP Control Panel v3.3.0 (Apache, MySQL)
